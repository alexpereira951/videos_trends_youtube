# Dashboard de tendências do YouTube

O objetivo deste projeto é criar uma automação de visualização de dados capaz de facilitar a análise de vídeos em alta no YouTube, ajudando a equipe de marketing da Sterling & Draper a identificar tendências e tomar decisões estratégicas com mais agilidade.

Este projeto analisa vídeos em alta no YouTube para apoiar as decisões de marketing da agência Sterling & Draper. Os dados incluem a categoria de cada vídeo, a região e a data em que ele entrou na seção de tendências. Como um vídeo pode permanecer em alta por vários dias, a análise considera sua presença ao longo do tempo.

O dashboard foi criado para facilitar o acompanhamento semanal e responder a três perguntas:

- Quais categorias estiveram em alta na semana anterior?
- Como os vídeos em alta se distribuíram entre as regiões?
- Quais categorias tiveram maior destaque nos Estados Unidos?
